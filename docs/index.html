code-doc-writer

A skill for coding agents. It writes and rewrites code comments and user-facing messages in short plain technical English, based on ASD-STE100 adapted for programming.

Source: github.com/Mr3zee/code-doc-writer

Use the agent's marketplace where it has one. The scripts are the fallback. Each one copies the skill folder into the agent's skills directory and nothing else.

Each script installs for the current user. To install into the current project, run it from the project root with the project flag:

curl -fsSL https://mr3zee.github.io/code-doc-writer/junie_install.sh | sh -s -- --project
